# 🎯 Dynamic Pricing Engine

AI-Powered Dynamic Pricing Optimization for E-Commerce using Machine Learning & Reinforcement Learning.

## 🚀 Features

- **Random Forest** - Tree-based pricing predictions with SHAP interpretability
- **XGBoost** - Gradient boosting with cost-sensitive learning
- **Reinforcement Learning (PPO)** - Adaptive pricing strategies
- **Time Series LSTM** - Price forecasting with temporal patterns
- **Model Ensemble** - Weighted combination for optimal predictions
- **Web Interface** - Flask-based interactive pricing dashboard

## 📁 Project Structure

dynamic-pricing-engine/
